# Swivel-Chair Capacity & Audit-Readiness Calculator (Companion App)

Self-contained, zero-dependency single-page app (`index.html`) designed as the off-platform interactive companion for the **Microsoft Finance AI & Audit Trail** LinkedIn Newsletter edition.

## Features
- **Tab 1 — Swivel-Chair Capacity Estimator:** Real-time sliders for staff count, weekly prep hours, loaded hourly cost, working weeks, and efficiency target (`40%` Microsoft Global Treasury call-prep benchmark preset), plus an interactive SVG capacity bar chart and workflow blueprint selector.
- **Tab 2 — 12-Point Audit-Readiness Scorecard:** Interactive 4-pillar control matrix with radial readiness gauge (`AI Theater Risk` / `Foundation Building` / `Audit-Ready`) and dynamically prioritized 30-day action items.
- **Executive Actions:** One-click `Copy CFO Briefing Summary` and print-friendly `Print / Save PDF Brief`.

## Quick Static Deployment (Pick Any Option)
1. **Netlify Drop:** Drag and drop the `companion-app/` folder onto [app.netlify.com/drop](https://app.netlify.com/drop) to get an instant HTTPS URL.
2. **GitHub Pages:** Commit `companion-app/index.html` to a repository (or `/docs`) and enable GitHub Pages.
3. **Vercel:** Run `npx vercel --prod` inside `companion-app/`.
